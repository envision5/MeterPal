## What is the Platform API?

The Platform API is for users who want to manage MeterPal on behalf of their users (for example, AI app builders) in a multi-tenant flow.

## How it Works

### 1. Create an Organization

Create an MeterPal organization linked to a user email. This generates API keys that your user can use to interact with MeterPal's billing features.

### 2. Integrate
Each organization created through Step 1 can use the deployment's shared PayPal account (the server's `PAYPAL_*` environment variables) for sandbox testing, so you can freely integrate and test MeterPal without your own PayPal credentials. When you're ready to go to prod, connect your user's PayPal account through Step 3.

### 3. Link PayPal Account

Connect the organization's own PayPal REST app with `POST /v1/organization/paypal`, passing `client_id` and `client_secret` (plus an optional `webhook_id`). MeterPal verifies the credentials against PayPal before storing them, and the PayPal environment follows the billing environment — a sandbox key connects a sandbox app, a live key connects a live one. See [PayPal](/documentation/concepts/paypal) for the full flow.

### 4. Manage the PayPal Connection

Use `GET /v1/organization/paypal` to check whether the org has its own PayPal connection for the active environment, so you can decide whether to show **Connect PayPal** or **Disconnect PayPal**. The response identifies the PayPal account (account email) and whether a webhook is registered.

Use `DELETE /v1/organization/paypal` to disconnect that environment's connection. Disconnecting does not delete the PayPal app or cancel its subscriptions, and the other environment's connection is preserved. To reconnect, call the connect endpoint again with fresh credentials.
