---

It's easy to move your existing customers to MeterPal. The MeterPal team will help you move your subscriptions and purchases over without any disruption. The main reasons teams migrate are:
- **Speed** - Team-based billing, multi-interval usage limits, auto-topups, timeseries charts: all handled by MeterPal out of the box.
- **Flexibility** — Plan versioning, custom deals, and pricing changes without code deploys
- **Reliability** — No webhook edge cases, race conditions, or state sync issues to debug

<Info>
Planning a complex migration? [Reach out to us](https://cal.com/ayrod) — we can help you plan and execute it.
</Info>

## Migration Steps

<Steps>
<Step title="Replace your existing billing code with MeterPal">
Start by integrating MeterPal in your development environment. Replace your existing billing logic with MeterPal's SDK:

- Set up your pricing plans in the [MeterPal dashboard](https://app.useautumn.com)
- Install the MeterPal SDK and configure your API keys
- Replace checkout, subscription management, and usage tracking with MeterPal equivalents

See our [setup guide](/documentation/getting-started/setup) for detailed integration instructions.

</Step>

<Step title="Map your products in production">
Before importing any customers, make sure every plan your customers are currently on has a matching plan set up in your MeterPal production environment. Each customer you import will reference one of these plans by its `plan_id`, so this mapping needs to be in place first.

</Step>

<Step title="Import your customers">
<Info>
Bulk imports are run by the MeterPal team. [Reach out to us](https://cal.com/ayrod) and we'll move your subscriptions and purchases over for you — **there will be no change or disruption to your customers' billing**.
</Info>

To move a customer over yourself, create the MeterPal customer and attach the matching plan:

```typescript
const autumn = new Autumn({ secretKey: "am_sk_..." });

await autumn.customers.getOrCreate({
  customerId: "user_123",
  name: "John Doe",
  email: "john@example.com",
});

await autumn.billing.attach({
  customerId: "user_123",
  planId: "pro",
});
```

If you need to preserve a customer's exact usage counts rather than have their balances reset on import, follow up with [`balances.update`](/api-reference/balances/updateBalance) to set the correct remaining balance for each feature:

```typescript
await autumn.balances.update({
  customerId: "user_123",
  featureId: "messages",
  remaining: 42,
});
```

</Step>
<Step title="Deploy your MeterPal integration">
Once your customers are imported, you can deploy your MeterPal integration to production. Your existing customers will be seamlessly linked to their subscriptions through MeterPal.
</Step>

</Steps>
